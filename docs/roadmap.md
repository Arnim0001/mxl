# Roadmap

## Draft 0.1
- JSON-based interchange format and examples
- Machine-readable schema and validation
- Reference timeline renderer and simulated outputs

## Mixel Studio alpha
- Drag-and-drop audio import and waveform display
- Editable multitrack timeline and cue/keyframe operations
- Audio feature extraction: tempo, onsets, energy and sections
- AI-assisted cue suggestions subject to manual review
- Open/save project and export/import MXL
- Simulation previews for lighting, screens and fountains

## Later milestones
- Hardware capability profiles and output adapters
- Measured timing diagnostics across desktop and mobile devices
- Controlled integration tests with physical equipment
- External interoperability tests and versioned releases

Do not represent proposed features as implemented until tests and code demonstrate them.
